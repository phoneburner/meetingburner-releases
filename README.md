# MeetingBurner desktop releases

This repository holds the MeetingBurner desktop app's release downloads, and nothing else.

Get the app from https://meetingburner.com/download, or from the Releases tab on this page.

There is no source code here. Each release is uploaded by MeetingBurner's own build when a new desktop version is published.

> **macOS note:** on first launch you may need to open System Settings > Privacy & Security and choose Open Anyway.
